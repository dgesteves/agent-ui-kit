Takes any `@ag-ui/client` agent (`HttpAgent`, or a framework integration's own `AbstractAgent`) and turns its messages and events into AI SDK message parts, so every component works with it unchanged, approvals included. Interrupts bound to a tool call become approval cards, and `respond` resumes the run. [AG-UI agents](/docs/ag-ui) has the event mapping, LangGraph and the pure functions behind the hook.
